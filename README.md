# 🎓 Thiệp Mời Tốt Nghiệp — Vy Anh | SE181832

> **FPT University HCMC · Niên khóa 2026**

Ứng dụng web thiệp mời tốt nghiệp cá nhân hóa. Người được mời nhập tên và trải nghiệm hành trình 4 năm đại học qua một câu chuyện tương tác trước khi xem thiệp mời chính thức.

---

## ✨ Tính năng

| Tính năng | Mô tả |
|---|---|
| 🎭 **Câu chuyện tương tác** | Hành trình 4 năm đại học được kể qua 7 cảnh với nhân vật hoạt hình và hiệu ứng đánh máy |
| 🖼️ **Ảnh hành trình thực tế** | Ảnh kỷ niệm qua từng năm học được lưu trữ và hiển thị qua Firebase Storage |
| 📱 **Tối ưu cho mobile** | Người dùng mobile được chuyển thẳng đến thiệp mời, bỏ qua menu lựa chọn |
| 🗓️ **Thêm lịch** | Hỗ trợ thêm sự kiện vào Google Calendar hoặc tải file `.ics` (Apple/Outlook) |
| 🌸 **Hiệu ứng cánh hoa** | Animation cánh hoa rơi trên màn hình thiệp mời |
| 🎵 **Nhạc nền** | Bật/tắt nhạc nền trong suốt trải nghiệm |

---

## 🚀 Chạy local

**Yêu cầu:** Node.js >= 18

```bash
npm install
npm run dev
```

Ứng dụng chạy tại: **http://localhost:3000**

---

## 🛠️ Tech Stack

- **React 19** + **TypeScript** — UI & logic
- **Vite 6** — Build tool
- **Motion** — Animations
- **Tailwind CSS v4** — Styling
- **Firebase Storage** — Lưu trữ ảnh hành trình đại học
- **Lucide React** — Icons
